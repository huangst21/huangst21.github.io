Songtao Huang（黄松涛）

Hi, welcome to my academic homepage! I’m a second-year Ph.D. student at Fudan University, advised by Wanli Ouyang. I’m fortunate to conduct research at Shanghai AI Laboratory, where I work closely with Shiyang Feng and Bo Zhang.

I’m interested in how to improve agents’ performance on long-horizon tasks, particularly for real-world work where agents can improve productivity. I’m also interested in recursive self-improvement (RSI) and how agents and their training environments can help each other improve over successive iterations.

Sage-A1.5 is a 35B mixture-of-experts model that runs subtasks in parallel using subagents with separate contexts. It monitors progress and checks evidence to revise its search strategy. LongHarness: Advancing Agentic Reasoning over 100M-Token Corpora via Stateful Evidence Management

Songtao Huang（黄松涛）, Zhijie Zhong, Xiaohan He, Shuaiyu Zhang, Zhiyin Yu, Li Kang, Heng Zhou, Yutao Fan, Xiangchao Yan, Bo Zhang, Shiyang Feng

Paper

arXiv · 2026.10

LongHarness supports reasoning over corpora that exceed the model’s context window by explicitly maintaining retrieved evidence and evolving conclusions. Gaps in the current conclusions guide what to retrieve next, and new evidence strengthens or revises those conclusions. Tracking the evidence lifecycle makes updates traceable. With the same GLM-5.3-Flash model, exact match on OfficeQA Pro V1 and V2 was 60.2% and 61.1% for LongHarness, 46.6% and 42.2% for Codex, and 48.1% and 35.6% for Claude Code, respectively.

Technical Report · 2026.06 Core Contributor

Agents-A1 is a 35B mixture-of-experts model trained on long-horizon interaction trajectories averaging 45K tokens. It combines expertise from six domains in a single model through domain-routed, multi-teacher on-policy distillation. On IFBench, Agents-A1 scored 80.6, compared with 71.8 for Kimi-K2.6 and 73.5 for DeepSeek-V4-Pro (Max).

Sci-CoE: Co-evolving Scientific Reasoning LLMs via Geometric Consensus with Sparse Supervision

Xiaohan He, Shiyang Feng, Songtao Huang（黄松涛）, Zongsheng Cao, Bin Wang, Bo Zhang

Paper / Code

arXiv · 2026.02

Sci-CoE addresses scientific reasoning tasks where verifiable feedback is scarce. It first trains a verifier on a small labeled set, then uses a geometric reward that balances consensus, reliability, and diversity to jointly train the solver and verifier on unlabeled data. In the GPQA-Diamond evaluation reported in v2, Qwen3-8B accuracy rose from 61.62% to 65.66% after the second training stage.

InternAgent: When Agent Becomes the Scientist -- Building Closed-Loop System from Hypothesis to Verification

InternAgent is a closed-loop multi-agent framework that connects hypothesis formation, method design, and experimental validation, with domain experts able to provide feedback throughout. RewardCode: Training Generalist Code Reward Model via Pairwise Reinforcement Learning

Songtao Huang（黄松涛）, Shiyang Feng, Xiaohan He, Xiangchao Yan, Bo Zhang, Lei Bai

Paper

Findings of EMNLP 2026

RewardCode combines rubric-based scoring with executable unit tests. It trains a general-purpose code reward model on the code preference pairs and unit tests in CodePair-18K and jointly optimizes scoring and test generation with Pairwise-GRPO. On RewardBench-Code, RewardCode-7B achieved 94.9% preference selection accuracy, compared with 88.8% for RM-R1-Qwen2.5-Inst-7B.

TimeKAN: KAN-based Frequency Decomposition Learning Architecture for Long-term Time Series Forecasting

Songtao Huang（黄松涛）, Zhen Zhao, Can Li, Lei Bai

Paper / Code

ICLR 2025

TimeKAN uses cascaded decomposition to extract representations for different frequency bands, models them with multi-order Kolmogorov–Arnold networks, and combines the band-level forecasts. On ETTh1, averaged over 96-, 192-, 336-, and 720-step forecast horizons, TimeKAN achieved an MSE of 0.417 and an MAE of 0.427, compared with 0.459 and 0.444 for TimeMixer.
